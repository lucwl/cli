# cli

A collection of nice command line tools that I use on a day to day basis. 

## Shell

[`ohmyzsh`](https://github.com/ohmyzsh/ohmyzsh) - Framework for customising zsh

[`envelope`](https://github.com/mattrighetti/envelope) - A modern environment variable manager

[`tldr`](https://github.com/tldr-pages/tldr) - A more concise version of `man` pages

## File system

[`ripgrep`](https://github.com/burntsushi/ripgrep) - Super fast recursive regular expression search, alternative to `grep`

[`ast-grep`](https://github.com/ast-grep/ast-grep) - Search command that understands your code's structure

[`fd`](https://github.com/sharkdp/fd) - Faster version of `find` with regular expression matching

[`zoxide`](https://github.com/ajeetdsouza/zoxide) - More intelligent version of `cd`

[`exa`](https://github.com/eza-community/eza) - Modern version of `ls`

[`bat`](https://github.com/sharkdp/bat) - Colourful version of `cat` 

[`fzf`](https://github.com/ohmyzsh/ohmyzsh) - High-performance command line fuzzy search

## Code editor

[`neovim`](https://github.com/neovim/neovim) - Vim but with (more) superpowers

## Database

[`lazysql`](https://github.com/jorgerojas26/lazysql) - TUI for database management

## Virtualisation

[`multipass`](https://github.com/canonical/multipass) - Effortlessly create lightweight Ubuntu VMs on any platform

## Language tooling

[uv](https://github.com/astral-sh/uv`) - Fast package and environment manager for Python

[`ty`](https://github.com/astral-sh/ty) - Fast type checker for Python

[`ruff`](https://github.com/astral-sh/ruff) - Fast linter for Python
